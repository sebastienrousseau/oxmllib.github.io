## WCAG 2.2 AAA

The documentation site is built with the **Lucid** theme and audited against strict accessibility standards:

- **Text Contrast (1.4.6 AAA):** Every text and background color pair achieves at least **7:1** contrast ratio.
- **Non-Text Contrast (1.4.11):** Interactive borders, controls, and focus states achieve at least **4.5:1** contrast ratio.
- **Target Size (2.5.5 AAA):** All interactive buttons and links have a minimum target size of 44x44 CSS pixels.

## Keyboard Navigation

- **Skip link:** Jump directly to primary content (`Skip to main content`).
- **Visible focus rings:** 3px high-contrast outline on all interactive elements.
- **Logical tab order:** Landmark roles (`header`, `nav`, `main`, `aside`, `footer`) structured in natural reading order.

## Responsive Reflow

- **320px Viewport (1.4.10):** The entire site reflows cleanly without horizontal scrolling at 320px width or 200% browser zoom.
